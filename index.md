[OpenHellion](pages/about) is a multiplayer RPG and sandbox set in space. You're a part of a mission-gone-wrong to colonise the nearest star. The goal is to survive in space, and to do such you need to follow a series of quests; these will guide you through the core concepts of the game. The game is also an open-world sandbox game, and allows you to build and manage your own space stations and ships.

The project is organised as a open-source effort, and contributions are therefore essential to the project. [Join our Discord](https://discord.gg/NqhQMfbjxW) to connect with the community and to learn more about the project.

---

The game can in its current state only be played by compiling it yourself, but you can check out the [installation and setup instructions](documentation/installation-setup) to learn how to set the game up. Because of large rewrites to the original, the game is not backwards-compatible.

Visit the [Hellion Documentation](documentation/home) for a more technical introduction to the game. You are also advised to check out the [source code](https://github.com/OpenHellion) and [about page](pages/about) if you want to learn more about OpenHellion.

The project is based on HELLION by Zero Gravity. It is unclear who the current owners of the game are, as the company that made it has gone bankrupt and there is little evidence of any buyers of the intellectual property. This project was started to let new people that never owned a copy of the game play it.
